DataPath · plataforma de avaliação de segurança

Visão geral — da autorização ao conserto

Uma plataforma que só testa sistemas com autorização comprovada, mapeia como a aplicação chega aos dados, confirma o risco com segurança e para no primeiro limite sensível — provando o risco sem causar o dano. Seis fases, construídas do portão para fora.

Recon seguro + detecção + relatório

✓ implementada

2

Confirmação ativa (opt-in) com parada no limite

✓ implementada

Confirma as falhas de maior valor (BOLA, privilégio vertical) com uma requisição só-leitura contra dados falsos (decoy). O corpo é descartado no portão; captura prova mínima mascarada e para no limite.

limite sensível prova mascarada corpo descartado não-explorado

python -m datapath.demo_fase2
